Process

How It Works

Our proven four-step workflow ensures every external scan is explicitly authorised and fully audited.

01
Sign Up & Request
Create your account and submit a key request from your dashboard
02
Admin Reviews
An admin reviews your request and approves or rejects it
03
Key Issued Once
Your unique 256-bit key is shown once on approval — copy it immediately
04
Authorise & Scan
Pass the key to the LUME CLI — it is consumed atomically for one scan

CLI Usage

lume scan prompt-injection \
  --target https://your-ai-endpoint.com/v1/chat \
  --authorized \
  --enterprise-key <your-key>
Security

Why Use the Enterprise Key Portal

We combine strong access controls with a simple workflow so every external scan is safe, traceable, and authorised.

One key, one scan
Each key is consumed atomically. Replay attacks and accidental reuse are impossible.
Admin-approved flow
Every key request is reviewed by an admin before a key is generated. No self-service bypass.
30-day expiry
Unused keys automatically expire after 30 days. Admins can revoke any key at any time.
Full audit trail
Every key issuance, consumption, and revocation is logged with timestamps and scan targets.
256-bit cryptographic keys
Keys are generated with secrets.token_urlsafe(32) — only the SHA-256 hash is stored, never the plaintext.
Fail-closed by design
If the key service is unavailable, external scans are blocked — never silently allowed through.

About the Portal

The TravLume Enterprise Key Portal is the access-control layer for LUME Security Toolkit scans against external AI endpoints. It enforces explicit, admin-reviewed authorisation before any key is issued.

Keys are generated server-side, shown to the user exactly once, and consumed atomically when a scan is authorised. Consumed keys can never be reused — if a scan fails after consumption, the user must request a new key.
